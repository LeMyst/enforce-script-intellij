# DayZ tools

The DayZ tooling beyond navigation: starting DayZ Tools and Workbench, running a server and clients,
following the game's logs, letting the engine check the scripts, building PBOs, the release
build and publishing it to the Steam Workshop, and creating mods and addons.

These work on Windows, from the folders in the [DayZ installation](../setup/dayz-installation.md)
settings.
