# Writing scripts

What the plugin does in Enforce Script (`.c`) files and in `config.cpp`: navigation and Quick
Documentation, completion and inlay hints, navigation from string literals, highlighting, colour
swatches, folding and formatting, generated overrides and templates, rename, and inspections.

Most of it reaches into vanilla DayZ and the dependency mods, so it needs their sources indexed:
see [Library roots](../setup/library-roots.md).
