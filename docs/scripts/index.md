# Writing scripts

What the plugin does in Enforce Script (`.c`) files and in `config.cpp`: navigation, completion,
navigation from string literals, highlighting, folding and formatting, rename, and inspections.

Most of it reaches into vanilla DayZ and the dependency mods, so it needs their sources indexed:
see [Library roots](../setup/library-roots.md).
