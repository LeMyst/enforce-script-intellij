Reports a name declared twice within one method.

A method body is a single flat scope in Enforce Script. Two if branches that can never both run may still not each declare int found; — the second is "Variable 'found' is already declared". Every other C-family language allows it, which is what makes this worth pointing out in the editor.

A for initialiser and a foreach variable each scope to their own loop, so repeating for (int i = 0; ...) is legal and is not reported.
