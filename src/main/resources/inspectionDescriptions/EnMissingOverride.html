Reports a method that redeclares one inherited from a superclass or one declared by another layer of the same modded class, without the override keyword.

The engine refuses this with "Function 'X' is already defined", but only when the mod is built, which on a full DayZ mod is minutes away from the edit that caused it.

A method is only reported when a base declaration of the same name takes the same number of parameters. Differing arity is an overload, which is legal and needs no keyword.
