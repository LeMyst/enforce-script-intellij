Reports a string that names a method the receiving object does not have.

AddTimer(5.0, this, "OnTick"), AddRPC(NS, "SetPlayerCount", this) and GameScript.Call(this, "ProcessPlayers", NULL) pass the method name as text, so the compiler never checks it. A typo, or a handler renamed without its registration, produces code that builds and links and then quietly never runs.

Only calls that name their target are checked. SendRPC and RemoveRPC do not say which object owns the handler, so nothing is reported for them.
