Reports a modded class for which no ordinary declaration of the same name is visible.

A layer names no supertype: it is bound to the class it patches by spelling alone. When the spelling is wrong the engine does not complain — it simply compiles the layer as a new class, so the mod builds, loads, and does nothing.

The other cause is harmless: the base exists but lives in a dependency mod whose sources are not among the configured script roots. Add it under Settings | Languages & Frameworks | Enforce Script and the report goes away.
