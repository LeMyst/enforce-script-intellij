Reports a STR_… key with no matching row in any stringtable.csv.

Applies to all three places a key is written: SetText("#STR_BR_WIN") in client script, text "#STR_BR_WIN" in a layout, and the bare key with no # that server script ships over a notification RPC.

A missing key is displayed to the player verbatim, so the mistake shows up on screen rather than in any log. Nothing is reported when no stringtable is indexed at all.
