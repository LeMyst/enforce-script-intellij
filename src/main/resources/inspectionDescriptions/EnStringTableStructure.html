Reports rows of a stringtable.csv that would put translations in the wrong place:
  • a row with more or fewer cells than the header, so every translation after the difference lands in the next language's column;
  • an unclosed quote, which turns the rest of the file into one cell;
  • text after the closing quote of a cell, or a quote inside an unquoted cell;
  • a key declared twice in the same file.

The game loads such a file without a word, so the mistake shows only when someone plays in the affected language.
